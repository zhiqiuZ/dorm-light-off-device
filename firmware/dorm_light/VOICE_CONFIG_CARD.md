| 事实 | 影响 |
|------|------|

## 烧录硬知识（官方 FAQ Q8/Q11/Q21 原文要点）

- 串口烧录走 **B6/B7（UART1）**：B7=TXD→转接头 RX、B6=RXD←转接头 TX（实测你的黑板 Type-C 只供电，此路是唯一烧录通道）；B0/B1 是调试器口，不用管；
- 进烧录模式：**短接 SW 线→重新上电**（不是拔插 5V 那么简单，按开发板丝印 SW 跳线/按键来）；失败就"回步骤1 重新短接上电"；
- **关掉杀毒软件**、**.bin 路径禁中文**、下载失败排查顺序：供电→SW→TX/RX 反接→换线换口换电脑；
- 功耗常识：03T 常听 **60mA**（FAQ Q14）——宿舍机 S8050 门控必焊，浅待机一晚 ≈1Ah，不焊等于白折腾。

```

      模块 B6→NodeMCU 底部 TX 针；模块 G↔NodeMCU G（共地！两路供电之间就靠它）。
      **回形针压住 NodeMCU 的 RST**（主控装死，CH340 变纯 USB-TTL）。
      接好对我说"接好了"——该看到的是 CH340 的 COM 口（不依赖主控活着）
[ ] T2 打开 http://www.smartpi.cn （⚠️ 用 http 前缀——https 证书吊销检查会报错；

[ ] T5 建 6 条命令词，每条的"动作/串口发送数据"填 A1~A6
[ ] T6 基本信息/固件配置：波特率 9600、音量最低、应答精简、降噪开
```

## 烧录失败速查（教程踩坑点名集）

| 症状 | 处置 |
|------|------|
| 工具搜不到串口 | CH340 口在不在（问我查）；RST 压紧了没；T9 的**拔插时机**：先点下载再拔插 Type-C |
| 下载中途失败 | 线松；**B6/B7 与 TX/RX 接反**（对照 T1 交叉表）；**.bin 路径含中文** |
| 刷完喇叭没声 | 供电 3.3V 喂不饱喇叭 → 5V |
| 刷完装置没帧 | 平台波特率没改 9600（出厂 115200，装置听不见） |
| 有帧但 hex 乱跳 | 平台"串口发送数据"字段没填/填了变量任务（settemp 那类要设成"串口输入"的别乱用） |

## 与固件侧的接口
