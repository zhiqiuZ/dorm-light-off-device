## 先知道的四个出厂事实（实测情报）

| 事实 | 影响 |
|------|------|
| 出厂波特率默认 **115200** | 之前"收到帧"=乱码假象，刷完 9600 才算真链路 |
| 喇叭供电 5V，**3.3V 可能不响** | 运行时红线必须接 5V 轨 |
| 平台支持**只说命令词不唤醒**模式 | "嫌唤醒词蠢"的官方解法就在这（见 §2 选择） |
| 命令识别后可**自定义串口发送内容** | 六条命令的数据我们**自己定**，帧天然互不相同——绑定零悬念 |

## 配置值（照抄；v2.1 按官方 FAQ 修订：docs.aimachip.com/zh-cn/latest/file/question/SU03T.html）

| 项 | 填 |
|----|----|
| 平台 | http://www.smartpi.cn/#/ ，Chrome/Edge，注册个账号 |
| 模组 | 创建新产品 → 选 **SU-03T** |
| 唤醒词 | **官方规则判了"1"死刑**：命令/唤醒词必须 **2~10 字**、**禁英文字母、禁阿拉伯数字（只能中文数字）**。两条正路任选：**① 免唤醒模式（官方支持最多 10 条命令裸触发）**——我们的 6 条全放进去，直接喊"关灯/开灯"，这就是你想要的"说一声就应"；② 保留唤醒词 → "幺幺幺"（3 字合规）。推荐先 ② 跑稳，再切 ① 体验误触发率 |
| 命令词 | `全关` `关左灯` `关右灯` `全开` `开左灯` `开右灯`（+2 条音量口令见下行，共 8 条 ≤10，免唤醒也够） |
| 音量口令 | 加两条命令词：`小声点`→action **volumeDownUni**、`大声点`→action **volumeUpUni**（官方音量就这么调的，还有 volumeMax/Mid/MinUni） |
| 每条命令的**串口发送数据** | 全关=`A1` 关左=`A2` 关右=`A3` 全开=`A4` 开左=`A5` 开右=`A6`（⚠️ 官方格式：**16 进制且要加空格**，多字节时每字节间空格；音量两条不发数据） |
| 串口波特率 | **9600**（出厂 115200，必须改） |
| 播报 | 唤醒应答最短；每条命令一句短应答；"小智"称呼可改（Q13：可以改） |
| 降噪 | 开 |

## 烧录硬知识（官方 FAQ Q8/Q11/Q21 原文要点）

- 串口烧录走 **B6B7 口**（模块的 TX/RX 就是烧录口——Type-C 若通到这俩脚即一线搞定；否则用杜邦接这俩脚到 USB-TTL）；
- 进烧录模式：**短接 SW 线→重新上电**（不是拔插 5V 那么简单，按开发板丝印 SW 跳线/按键来）；失败就"回步骤1 重新短接上电"；
- **关掉杀毒软件**、**.bin 路径禁中文**、下载失败排查顺序：供电→SW→TX/RX 反接→换线换口换电脑；
- 功耗常识：03T 常听 **60mA**（FAQ Q14）——宿舍机 S8050 门控必焊，浅待机一晚 ≈1Ah，不焊等于白折腾。

## 十步流程

```
[ ] T1 Type-C 数据线插电脑（必须是数据线！）→ 对我说"插上了"，
      我查串口基线（当前 COM4/5/6）——多出新口=模块枚举成功
[ ] T2 打开 https://smartpi.cn/ ，注册/登录
[ ] T3 创建新产品 → 模组选 SU-03T
[ ] T4 唤醒词按上表录（免唤醒模式的取舍自己拍）
[ ] T5 建 6 条命令词，每条的"动作/串口发送数据"填 A1~A6
[ ] T6 基本信息/固件配置：波特率 9600、音量最低、应答精简、降噪开
[ ] T7 提交生成固件（云端编译，快则几十秒慢则几分钟，等着）
[ ] T8 下载生成的 .bin（随机长文件名）→ **移到桌面**（路径不许有中文，
      这是教程点名的第一大坑）
[ ] T9 烧录：用资料页/平台给的下载工具 → 它自动搜串口，不用手选 →
      ⚠️ 点"下载/烧录"后**必须重新拔插模块 5V/Type-C**才进下载模式
      （教程原话：软件点下载后，需断电再连接！）→ 等"下载成功"
[ ] T10 运行接线复位：模块 V→5V 轨、G→GND、TX→**D7/GPIO13**；
      装置醒着开页面 → 喊"全关"两遍 → 最近帧两次 hex 应都是 A1 →
      六行逐行【学】绑定（现在帧是自定义的，绝不重号）→ 实战
```

## 烧录失败速查（教程踩坑点名集）

| 症状 | 处置 |
|------|------|
| 工具搜不到串口 | 线是充电线？T9 的**拔插时机**：先点下载再拔插供电 |
| 下载中途失败 | 线松；TX/RX 反接（若走外接 TTL 而非 Type-C）；**.bin 路径含中文** |
| 刷完喇叭没声 | 供电 3.3V 喂不饱喇叭 → 5V |
| 刷完装置没帧 | 平台波特率没改 9600（出厂 115200，装置听不见） |
| 有帧但 hex 乱跳 | 平台"串口发送数据"字段没填/填了变量任务（settemp 那类要设成"串口输入"的别乱用） |

## 与固件侧的接口

绑定的就是模块发来的 `A1~A6` 单字节，60 秒学完 6 行；网页/语音同锁同去重照旧；S8050 门控补焊提醒仍然有效（浅待机省电）。
