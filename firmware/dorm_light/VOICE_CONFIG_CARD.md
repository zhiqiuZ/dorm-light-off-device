# VOICE_CONFIG_CARD — SU-03T 配置照做卡（零决策版）

> 用法：从 T1 走到 T10。每一步做完在行首打 `[x]`；**卡住就把工具上看到的按钮/提示文字原样念给我**，我按词表接你下一步。
> 接线二选一：模块有 USB 口 → T1 走 A 路；没 USB 口 → B 路（借 NodeMCU 的 TX/RX 针）。

## 配置值（全部照抄，不用再想）

| 项 | 填 |
|----|----|
| 波特率 | **9600** |
| 识别结果串口输出 | **开** |
| 唤醒词 | 先录 **"1"**（工具嫌短拒收 → 换 **"幺幺幺"** → 还拒 → "小灯小灯"） |
| 命令词 6 条 | `全关` `关左灯` `关右灯` `全开` `开左灯` `开右灯` |
| 唤醒应答 | 最短档（"滴"一声，没有就选最短语料） |
| 命令应答 | 每条留一句短的（"已关灯"），演示罐头音能删全删 |
| 音量 | **调最低档，装机后再加**（宁小勿吵） |
| 命令有效期 | 默认 7 秒 |

## 十步流程

```
[ ] T1 物理连接
      A 路（模块有 USB）：数据线插电脑。插好对我说"模块插上了"，
        我查串口表——出现新 COM 口=连接成功；没有=换根线（必须是数据线，
        很多充电线不通数据，这是第一大暗坑）。
      B 路（无 USB）：模块 TX→NodeMCU 底部 RX 针、模块 RX→TX 针（不是 D6/D7！），
        NodeMCU 插电脑，工具打开瞬间按住 FLASH 不松。
[ ] T2 打开厂商配置工具（卖家链接/说明书里的网页工具，Chrome/Edge；
      找不到链接就对我说，我们搜"SU-03T 配置工具"）
[ ] T3 工具里"连接串口/打开设备"→ 选新出现的 COM 口（A 路）或 COM5（B 路）→ 连
[ ] T4 首次读回出厂配置（若工具要求先"读取/下载配置"，做）
[ ] T5 按上表逐项填参数
[ ] T6 录唤醒词：工具进录音模式→对模块麦喊两遍→保存（安静房间，距离 20~40cm）
[ ] T7 建 6 条命令词（词面照抄；有"识别阈值"选默认/中档）
[ ] T8 音量+应答精简（见上表）
[ ] T9 保存并下载到模块 → 等进度条走完 → 模块重新上电一次
[ ] T10 恢复运行时接线：模块 TX 挪回 D7/GPIO13（B 路借的针必须还原！），
      V 回 5V 轨、G 回 GND → 装置醒着时开页面：
      喊"唤醒词+全关"两遍 → 最近帧两次 hex 一致 → 六行逐行【学】绑定 → 实战
```

## 常见卡点速查

| 症状 | 先查 |
|------|------|
| 工具连不上/选不到口 | 数据线！B 路 FLASH 按住了吗？口被串口监视器占用？ |
| 读取配置失败 | FLASH 键在打开工具瞬间就要按住，连上才松 |
| 唤醒词被拒 | 按备选链降档："1"→"幺幺幺"→"小灯小灯" |
| 烧录进度不动 | 断开重连；B 路检查 TX/RX 有没有插反（插 RX0/TX0，不是 D6/D7） |
| 配置成功但没帧 | T5 那格"串口输出"真开了吗；hex 乱变=波特率没改 9600 |
| 喊命令不响应 | 模块侧先要唤醒词应答（"滴"）之后 7 秒内说命令 |
