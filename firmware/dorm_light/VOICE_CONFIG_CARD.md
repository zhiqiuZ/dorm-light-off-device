# VOICE_CONFIG_CARD v3 — SU-03T（智能公元）配置照做卡（零决策·官方 16 页快速上手 PDF 实据版）

> 2026-11-25 定案：情报源 = 官方《SU-03T快速上手基础教程》PDF 全文解剖（help.aimachip.com 附件1381）+《上位机发送数据.txt》帧样例 + 官方 FAQ。
> 你这颗是芯路城"2.54mm 黑板"：**Type-C 实测只供电**（插上无新 COM），烧录/运行数据都在 **UART1：TX=B7、RX=B6**。
> 卡住就念屏幕上的按钮/字段名，我按速查表接你。

## 一、出厂四事实

| 事实 | 影响 |
|------|------|
| 出厂默认波特率 115200 | 之前"收到帧"=乱码假象；平台里改 9600 |
| 帧格式 = `AA 55 <编号>… 55 AA` 官方风格（≤6B） | **不用手灌发送数据**：命令词填"行为名"，模块自动裹帧；学习绑定整帧照学 |
| 喇叭要 5V（3.3V 不响）；板载 3V3 LDO≤150mA 可输出 | 运行时红线接 5V 轨 |
| 03T 常听 60mA | S8050 门控必焊（浅待机一晚 ≈1Ah） |

## 二、平台配置值（照抄）

| 屏 | 填 |
|----|----|
| 入口 | `https://smartpi.cn/#/`（打不开就搜索框输入"智能公元"）；注册→**微信扫码绑定**才进平台；悬停型号=快速创建工程 |
| 产品类型/名称 | 类别随便（官方示例"RGB灯"）；名称自定义；语言中文 |
| **Pin 脚配置** | 按规格书选 **UART：TX=B7、RX=B6**；**IO/GPIO/PWM 全不配**；UART0(B0B1) 不碰；B8 随意 |
| 唤醒词 | `幺幺幺`（2~10 字，禁字母/阿拉伯数字）；唤醒灵敏度=高；应答最短 |
| 命令词表 | 6 行+每行**串口发送参数（整帧 HEX 带空格）**：全关=`AA 55 01 55 AA`、关左灯=`AA 55 02 55 AA`、关右灯=`AA 55 03 55 AA`、全开=`AA 55 04 55 AA`、开左灯=`AA 55 05 55 AA`、开右灯=`AA 55 06 55 AA`；回复语短。音量两条不填串口参数。⚠️ 若烧后"最近帧"出现双裹长帧(>8B)→参数改只填编号字节 `01`~`06` 重烧 |
| 添加控制四类 | 端口输出/变量设置=**不用**；播放语音=回复；系统设置=音量（`小声点`/`大声点` 两条口令选减小/增大音量） |
| 免唤醒 | 左侧勾命令词→右移按钮（**先不启用**，跑稳再说，上限 10 条） |
| 识别灵敏度 | 高 |
| 开机播报 | 无（免吵）；有=内容自定 300s |
| 发音人 | 随意（音色/音调/语速） |
| 串口参数 | **波特率 9600**、8N1、HEX |

## 三、烧录十步（官方 PDF 21~26 精化）

```
[ ] F1 装 CH340 驱动（CH341SER.EXE，开发包资料里有）→ NodeMCU 插电脑，
      设备管理器看 COM 号（或问我查）
[ ] F2 固件压缩包解压到**每一层都纯英文**的路径（桌面若中文名就放 D:\fw\）
[ ] F3 认准解压产物：jx_su_03t_release_update.bin
[ ] F4 烧录软件=小扳手 UniOneUpdateTool.exe —— 本机已有：
      D:\SU03T\Hummingbird-M-Update-Tool\（unionedebug.ini PORT=4 若与实际 COM
      不符，改成实际号）；选 bin → 打开
[ ] F5 接线（先接线后供电！）：模块 B7→转接 TX、B6→RX、G↔G；
      转接=NodeMCU 底部 TX/RX 针（CH340 直连），**回形针压住其 RST**；
      杜邦插紧（官方警告 2.54 端子易接触不良，你这板是 2.54 排针版，问题不大）
[ ] F6 模块供电：Type-C 插电脑/充电头
[ ] F7 点【烧录】→ 进度条变黄显示"等待设备"
[ ] F8 **拔模块 5V（Type-C）等 2 秒插回** → 出百分比进度条
[ ] F9 到 100% 绿字=成功 → 断电重启模块（⚠️ 供电中别热拔插*换模块*，易烧功放；
      这里指模块插座，拔插自己这块的供电线做触发是官方流程本身）
[ ] F10 恢复运行接线：B7 从转接 TX/RX 针挪回 **D7/GPIO13**；V→5V轨、G→GND
```

## 四、验收三连（装置侧，固件零改动）

1. 装置醒着（窗口内）→ 开页面「语音/夜间模式」→ 最近帧=sniffer；
2. 喊"幺幺幺+全关"两遍 → **两次 hex 一致**（应是 AA55xx…55AA 式）=真链路毕业；
3. 六行逐行【学】绑定 → 实战三判据：语音触发舵机空载 / 30s 同令去重 / 网页语音同锁互斥。

## 五、失败速查

| 症状 | 先查 |
|------|------|
| 工具搜不到口 | CH340 驱动装了没；ini PORT 对不对；问我查 COM |
| 黄色等待不动 | F8 的拔插节奏（点烧录**之后**再拔插）；线松 |
| 下载中途报错 | 路径含中文；杀毒软件关；换 USB 口 |
| 刷完喇叭没声 | 5V 供电没到位（3.3V 喂不饱） |
| 刷完没帧 | 平台波特率没改 9600；或 B7 没接回 D7 |
| hex 乱跳 | 出厂固件没被刷掉（重烧一遍，检查成功绿字） |
| 绑定时六行学到同一帧 | 行为名没填对（A1~A6 必须各不相同、英文开头） |
