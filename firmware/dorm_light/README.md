## 1. 如果用 Arduino IDE（可选，不是必须）

1. Arduino IDE（2.x 或 1.8.x 均可），首选项 → 附加开发板管理器网址：
   `http://arduino.esp8266.com/stable/package_esp8266com_index.json`
2. 开发板管理器 → 搜 `esp8266` → 安装 **esp8266 by ESP8266 Community**（≥2.7.4，建议 3.1.x）。
3. 开发板选 `NodeMCU 1.0 (ESP-12E Module)`；COM 口不出现 → 装 CH340 驱动。
4. **【F-6 关键一步】工具 → Flash Size**：
   - 板子实为 4MB（ESP-12E/F 常见）→ 选 **`4M (1M SPIFFS)`**（含双 OTA 分区，FR-9 可用）；
   - 只有 1MB 可选 → 是 1MB 板：**OTA 作废**（PRD R7），其余功能不变。
   - （CLI 的 `eesz=4M1M` 就是这条的命令行等价物；上电后打开 `192.168.4.1/diag`，`flashSize` 字段直接告诉你真实容量——F-6 当场结案。）
5. 也可以完全不开 IDE：用第 0 节的脚本就行。

## 2. 首次烧录

1. USB 连电脑 → 选本工程 → 上传。
2. 串口监视器 115200：应看到
   `[net] AP 'GUANGDENG' ch=1 ip=192.168.4.1` 与 `[boot] ready`。
3. 手机连热点 `GUANGDENG`（密码 `111222345`）→ 浏览器开 `http://192.168.4.1` → 应见"全关 + 左右灯"主页（右下角 v2.0.0）。

## 2.5 现有货品台架接法（2026-09 盘点：板/18650/升压模块/MG90S+SG90/杜邦线在手，TP4056 和电容未到）

```
18650 (+) ── 升压模块 IN+      升压 OUT+ ─┬─ NodeMCU Vin/VU 孔（外部 5V 的正确入口）
18650 (-) ── 升压模块 IN-      升压 OUT- ─┼─ NodeMCU G   ← 共地，必接
  (红线)                        (红线)     ├─ 左舵机 红 V+ ┐ 各并此轨
  (黑线)                        (黑线)     ├─ 右舵机 红 V+ ┘ 两棕并 OUT-
信号（D8 双通道）：左舵机 橙 ── D2 (GPIO4)；右舵机 橙 ── D5 (GPIO14)
```

- 升压若是**固定 5V 输出**：直接接。若是**可调（MT3608 类）**：先空载用万用表拧到 5.0V 再接负载；没表就先带 SG90 空载试，MG90S 带载前想办法搞到表（3 元那种也行）。
- **单电源纪律**：烧录时=只插 USB（把电池链整条拔掉）；跑动作时=只挂电池链（拔掉 USB）。两者并存会双电源打架。
- **电容到货前**：只做空载/轻载测试且速度档 ≤2；MG90S 满行程带连杆的耐久（AC-4）留给电容到位后——它堵转 ~1.5A，超过 MT3608 级模块的舒适输出。**两舵机的电流叠加风险已由固件排除**：全局单锁串行执行，任何时刻只有一只通电（"全关"= 先左后右，约 4 秒）。
- **TP4056 到货前**：没电就抠下 18650 用别的充电器充/备一节轮换；到货后接回 PRD §6 常挂链，台架接法升级为"边用边充"。
- 升压板发烫、或动作瞬间热点瞬断 = 输出电流不足 → 换 XL6019 级 5V/3A 模块（PRD R1 ⑤）。
- ⚠ 别把舵机红线插 `VU/VIN` 又同时用 USB 供电指望它有电——USB 态那孔被二极管隔离≈0V（本次踩坑实录，§5 首条）。

## 2.6 语音 + 夜间深眠接线（v3.0.0 / D9+D10）

```
SU-03T 红 V ──────────── 5V 轨（与舵机同轨）
SU-03T 黑 G ─── 三极管 S8050 集电极；发射极 ── G 轨（门控：不醒就不供电，省电 30~50mA）
三极管 基极 ── 1kΩ ── NodeMCU D8/GPIO15（开机天然低电平=关，安全）
SU-03T TX（模块发） ── D7/GPIO13     SU-03T RX ←── D6/GPIO12（v3 预留）
```

**SU-03T 一次性配置**（厂商配置工具，Windows+网页串口）：
- 波特率改 **9600**（SoftwareSerial 收 115200 不可靠，这条不做全盘皆输）；
- 录唤醒词（建议"小灯小灯"）+ 建 6 条命令词（全关/关左灯/关右灯/全开/开左灯/开右灯），开"识别结果串口输出"；
- 模块没 USB：烧录时借 NodeMCU 当 USB-TTL——TX/RX 交叉接 D6/D7 与模块，**打开配置工具的瞬间按住板上 FLASH 键**（让主控复位、让线说话），连上后松开。

**学习绑定**（烧 v3 后）：页面「语音 / 夜间模式」→ 每行点【学】→ 15 秒内喊唤醒词+对应命令 → 该行出现十六进制帧=绑定成功。6 行学完，语音全通。"最近帧"区是内建 sniffer，可随时排查。

**夜间模式验收**：页面开过一次（=时钟已同步）→ 到窗口外闲置 5 分钟 → 热点应消失；到点自动重现。期间手动按开关照常（装置松劲）。

## 3. 台架验证顺序（FIRMWARE_DESIGN §十五，每步过不了不往下走）

| 步 | 动作 | 判定 |
|---|---|---|
| 1 | 空载（**不粘压爪**），设置页逐通道"试·关左/开左/试·关右/开右" | 每只舵机按设定角走完并**松劲**（断电后轴能徒手转动）= 正常 |
| 2 | 串口 50 次连点 | `freeHeap` 不下滑、无 `[act] FAULT`（AC-4 预演） |
| 3 | 改角度→试动作→保存→**拔电重连** | 参数还在（`calibrated` 保持） |
| 4 | 干跑校验：把关灯角=中位角 | 保存被拒（`angles_conflict` 提示） |
| 5 | 4 台设备同点 | 先到执行、其余收到"上一个操作还在进行" |
| 6 | （确认 4M 分区后）`build_firmware.bat` 导出的 `dorm_light.ino.bin` → 页面"固件更新"传自己 | 上传→重启→45 秒"验证中"横幅→自动解锁 = OTA 链路全通 |

## 5. 已知边界（诚实清单）

- ⚠ **舵机电源别取板上 `VIN/VU/VV` 孔**（实机踩坑 2026-09）：不少板该孔被防倒灌二极管与 USB-5V 隔离，USB 供电时输出≈0V → 造成"舵机全程没通电"假象（不动、不热、动作日志正常、热点不断）。要用板上真 `5V` 孔（多与某个 `G` 并排在角落），或干脆走 MT3608 母线 + 共地。
- AP 模式无轻睡眠（PRD R2）→ 常挂链 USB 供电是前提，纯电池约一天。
- 接入约 4 台上限（OA-5）；装置无真实时钟，"上次 X 分前"由手机换算（D-10）。
- 45 秒存活窗是"软回滚"：崩得连 HTTP 都起不来时，兜底仍是 GPIO0+USB 重烧 —— 所以装置必须装在 30 秒能拔线下墙的位置（PRD §8.3）。
- 舵机堵转无法检测（无电流反馈，§4），只有 3 秒硬断电。
- 代码已用 esp8266 core **3.1.2 编译通过**并**实机运行**（v1.0.1：热点/网页/动作日志/无掉电均正常）；剩余为机械/供电侧台架项，见 PLAN Day 表。
